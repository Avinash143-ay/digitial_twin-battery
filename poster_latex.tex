\begin{block}{Problem Statement}

Battery management systems require accurate real-time prediction of voltage and temperature with uncertainty estimation for:

\begin{itemize}
\item Safety monitoring and thermal runaway prevention
\item State-of-Health (SOH) estimation
\item Remaining useful life prediction
\item Adaptive charging strategies
\end{itemize}

Traditional physics-based models are computationally expensive for real-time deployment, while single AI models often fail to capture prediction uncertainty.

\end{block}

\vspace{1cm}

\begin{alertblock}{Our Solution}

We propose a \textbf{dual AI architecture}:

\begin{enumerate}
\item Transformer model for fast parallel prediction
\item Deep ensemble model for uncertainty-aware forecasting
\end{enumerate}

Both models are trained on the \textbf{KIT Battery Aging Dataset (Nature Scientific Data 2024)} using the \textbf{P065 lithium-ion cell}.

\begin{itemize}
\item Temperature: 0°C
\item SOC Window: 10–100\%
\item Cell Type: 18650 Li-ion (2Ah)
\end{itemize}

\end{alertblock}

\begin{block}{Model 1: MoE-Enhanced Transformer}

\textbf{Architecture}

\begin{itemize}
\item Input: Relative age, voltage, temperature, current sequence
\item \textbf{3 Cascaded MoE Layers}
\begin{itemize}
\item Layer 1: 64→100 dims, 1000 experts
\item Layer 12: 100→50 dims, 1000 experts
\item Layer 13: 10→2 dims, 1000 experts
\end{itemize}
\item \textbf{Top-20 Dynamic Routing} per layer
\item Transformer: 2-layer encoder (64 dim, 2 heads)
\item Output: Dual-branch μ/σ for V \& T
\item Parameters: ~500K
\item Prediction horizon: 150 steps
\end{itemize}

\textbf{Performance}

\begin{itemize}
\item \textbf{Voltage MAPE: 0.158\%} ⭐
\item Temperature MAPE: 0.698\%
\item \textbf{Win Rate: 94.4\%} (17/18 segments)
\item Fast inference (<50 ms)
\item Uncertainty quantification (μ, σ)
\end{itemize}

\end{block}

\vspace{1cm}

\begin{block}{Model 2: Deep Ensemble}

\textbf{Architecture}

\begin{itemize}
\item Input: Relative age, voltage, temperature, current
\item Ensemble size: 10 neural networks
\item Parameters: 200K each → 2M total
\item Activation: GELU
\item Prediction horizon: 75 steps
\end{itemize}

\textbf{Performance}

\begin{itemize}
\item Voltage MAPE: 0.3-0.4\%
\item Temperature MAE: 0.8-1.2°C
\item Win Rate: 5.6\% (1/18 segments)
\item Inference time: ~200ms
\item Uncertainty quantification via spread
\end{itemize}

Final prediction is obtained using the \textbf{median of ensemble outputs}.

\end{block}
